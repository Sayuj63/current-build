CURRENT BUILD — TEXT VERSION

Sayuj Pillai

I build systems that turn ambiguity into something that works. Fragmented briefs, half-specified problems and unowned processes go in; running, maintainable systems come out. Below is the same record the interactive version tells, in plain text.

Origin

B.Tech Computer Science and Engineering at ITM Skills University, 2024–28 batch. The starting condition was not a plan. It was one small question repeated across unrelated domains: what would it take to make this actually run in production, for someone other than me?

Chaos

Breadth first, deliberately. Storefront engineering, quantitative research, DevOps provisioning, knowledge-graph design, CLI tooling, charity sites, CRM systems. The experiments were not a portfolio strategy; they were the sampling phase. Most were discarded. The ones that survived did so because they were used by people who were not me.

Assembly

The repeated shape underneath all of it: discovery and specification, then architecture, then implementation, then deployment, then the unglamorous post-launch support where the real defects live. The same sequence applies whether the artifact is a storefront theme or a research pipeline.

Commerce

Production Shopify architecture across live merchant stores, including ISOA, Almost Always, Radiant & Keen, The Curated Collective, Adore Nails, Calvium, AEQEA and Seba Digital. The work is theme architecture rather than theme editing: cross-SKU colour swatch systems that resolve the correct variant across separate products, AJAX cart behaviour, design-token systems that keep a brand consistent across every section, Liquid section and block schemas built for merchants to operate without a developer, plus catalogue import pipelines that turn vendor linesheets into thousands of correct product rows.

A representative defect and its fix: a colour picker updated its visible selection but not the hidden variant ID, so the cart silently received the wrong variant. The fix was not a patch on the click handler — it was replacing the picker's implicit state with a resolved variant lookup derived from a variants JSON payload, so the visible selection and the submitted value could no longer diverge.

Projects — showcase

Live storefront systems and named projects. Each entry either links to the running site or, where the client has asked us not to name the URL publicly, resolves to the source repository. If a link is missing, the store is behind a private staging URL.

    Intelligence

    Turning data into a decision rather than a dashboard. Onboarding, university and mentor discovery, AI-assisted essay construction and admit-chance visualisation — the useful output is a route through complexity, not a larger pile of complexity rendered prettily.

    Trust

    A document verification system anchored on-chain: hash the artifact with SHA-256, commit the digest, and you have a tamper-evident audit trail where verification does not require trusting the party that stored the file. Certainty is the product. The interactive version of this page computes a real digest in front of you.

    Autonomy

    A quantitative research pipeline against the WorldQuant BRAIN platform: programmatic candidate alpha generation, asynchronous simulation submission, result polling, lineage tracking so every candidate is traceable to the hypothesis that produced it, rate-limit handling, and automatic submission of candidates that clear the platform's criteria. The system's value is that it keeps working while I am asleep, and that it records why it did what it did.

    People

    A 500+ member hackathon club, and workshops whose only success metric is whether the attendee shipped something end to end afterwards. Teaching is the highest-leverage form of the same behaviour: one working system becomes many, run by people who no longer need me.

    Failure

    Not every system survived. Some were abandoned mid-architecture, some shipped and were quietly replaced, some broke in production and had to be understood under pressure. The honest version of this record includes the unresolved states. Systems that have never failed have usually never been used.

    Rebuild

    The projects were never separate interests. Commerce, quantitative research, verification and provisioning are all the same behaviour applied to different material: take an ambiguous input, find its real structure, make that structure executable, then make it maintainable by someone else.

    Current build

    Currently: production storefront systems for live merchants, an autonomous alpha research pipeline, and a domain-agnostic knowledge-graph substrate for turning unstructured sources into queryable structure. This page is itself part of the current build.

    Unknown

    Deliberately undefined. The next system is not on this page because it does not exist yet. Build continues.
